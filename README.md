
# Even or Odd Number Checker

## Description
A beginner-friendly Python program that checks whether a given integer is even or odd.

## Concepts Learned
- User input
- Integer conversion
- Modulo operator (%)
- Conditional statements (if/else)
- Comparison operators

## How It Works
The program receives an integer from the user.
It divides the number by 2 and checks the remainder.

- Remainder 0: Even
- Remainder 1: Odd

## Example

Input:
8

Output:
The number is even.

## How to Run

Run the following command:

python even_odd.py
